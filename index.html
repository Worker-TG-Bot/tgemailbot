📋 部署步骤

1

创建 Telegram Bot

  1. 在 Telegram 搜索 @BotFather
  2. 发送 /newbot 创建新 Bot
  3. 按提示设置名称，获取 BOT_TOKEN
2

创建 Google OAuth 凭证

  1. 访问 Google Cloud Console
  2. 创建项目（如已有可跳过）
  3. 创建 OAuth 2.0 客户端 ID（选择 Web 应用类型）
  4. 添加授权重定向 URI： https://your-worker.your-username.workers.dev/oauth/callback
  5. 启用 Gmail API
  6. 记录 CLIENT_ID 和 CLIENT_SECRET
⚠️ 注意：如果应用未发布，需在 OAuth 同意屏幕添加测试用户（你的 Gmail 地址）
3

创建 Cloudflare Worker

  1. 登录 Cloudflare Dashboard
  2. 进入 Workers & Pages → Create application → Create Worker
  3. 给 Worker 起名（如 gmail-bot）
  4. 点击 Deploy 创建
4

创建 KV Namespace

  1. Workers & Pages → KV → Create namespace
  2. 名称填 USER_TOKENS
  3. 进入 Worker Settings → Variables → KV Namespace Bindings
  4. Add binding：Variable name 填 USER_TOKENS
5

设置环境变量

在 Worker Settings → Variables → Environment Variables 添加：

BOT_TOKEN = 你的 Telegram Bot Token
BOT_SECRET = 自定义密码（如 mysecret123）
GOOGLE_CLIENT_ID = OAuth Client ID
GOOGLE_CLIENT_SECRET = OAuth Client Secret
PUBSUB_TOPIC = （可选）projects/项目ID/topics/主题名
💡 建议将 GOOGLE_CLIENT_SECRET 设为加密变量（Encrypt）
6

复制代码到 Worker

  1. 在 Worker 页面点击 "Edit code" 或 "Quick edit"
  2. 删除默认代码
  3. 打开 GitHub 项目，复制其中的 worker.js 文件内容并粘贴
  4. 点击 Save and Deploy
7

一键设置 Webhook

浏览器访问以下地址完成设置：

https://your-worker.workers.dev/setup?secret=你的BOT_SECRET

看到 "✅ 设置成功" 即完成

选

配置实时推送（可选）

  1. 进入 Google Cloud Pub/Sub
  2. 创建 Topic（如 gmail-notifications）
  3. 给 Topic 添加权限：gmail-api-push@system.gserviceaccount.com → Pub/Sub Publisher
  4. 创建 Push Subscription，端点：https://your-worker.workers.dev/pubsub/push?secret=BOT_SECRET
  5. 添加环境变量 PUBSUB_TOPIC
  6. 设置 Cron Trigger：0 0 * * *（每天自动续期 watch）
✓

开始使用！

  1. 在 Telegram 找到你的 Bot
  2. 发送任意消息或点击 开始
  3. 使用底部按钮菜单操作
  4. 点击 👤 账户管理 → ➕ 添加账户 绑定 Gmail

🔧 常见问题

授权时提示 "Access blocked" 或 "未经验证的应用"

这是因为 Google 应用未发布。解决方法：

  1. 进入 Google Cloud Console → OAuth 同意屏幕
  2. 在"测试用户"中添加你的 Gmail 地址
  3. 或者发布应用（需要验证）
提示 "redirect_uri_mismatch"

重定向 URI 不匹配。确保 Google Console 中的授权重定向 URI 完全匹配：

https://your-worker.workers.dev/oauth/callback
Bot 没有响应
  1. 确认已访问 /setup?secret=xxx 设置 Webhook
  2. 检查 Worker 日志是否有错误
  3. 确认环境变量配置正确
  4. 确认 KV Namespace 已绑定
底部按钮不显示

ReplyKeyboard 按钮需要 Bot 发送一次消息后才会显示。尝试：

  1. 向 Bot 发送任意消息
  2. 或发送 /start 命令
  3. 按钮会出现在输入框上方
推送功能不工作
  1. 确认已创建 Pub/Sub Topic 并配置 PUBSUB_TOPIC 变量
  2. 确认 Push Subscription 端点正确
  3. 确认 gmail-api-push@system.gserviceaccount.com 有发布权限
  4. 在 Bot 中点击 ⚙️ 设置 → 🔔 开启推送
  5. 设置 Cron Trigger 每天续期 watch
网页预览链接打不开
  1. 链接有效期为 1 小时，过期后需重新生成
  2. 链接包含安全 token，仅授权用户可访问
  3. 确保网络可以访问 Cloudflare Workers
